### 🛡️ SURAKSHA-SETU

**AI-Assisted Disaster Management Decision-Support System**

SURAKSHA-SETU is a disaster-management intelligence system designed to analyze environmental, geographical, historical, and vulnerability-related factors to support hazard assessment and relocation decisions.

#### Key capabilities

- Flood risk assessment
- Landslide risk assessment
- Environmental data analysis
- Hazard-zone intersection
- Risk scoring
- Vulnerability analysis
- Priority identification
- Evacuation and relocation support
- GIS/spatial processing

#### Technology

- Python
- FastAPI
- React
- SQLite
- Shapely
- Haversine distance calculations
